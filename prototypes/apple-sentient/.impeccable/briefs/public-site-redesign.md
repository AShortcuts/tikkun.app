# Public Site Redesign Brief

## Approved Visual

`.impeccable/mocks/home-mobile-approved.png`

## Composition Commitments

- Compact brand, Menu, and Open reader header.
- Concise two-line hero with a single primary action aligned right.
- Large, frontal, authentic reader product media.
- A clear dark-to-paper section transition.
- A working four-theme selector tied to the whole public treatment and reader media.
- Purpose-specific secondary pages rather than repeated cinematic landing sections.

## Implementation Inventory

| Ingredient | Medium | Commitment |
| --- | --- | --- |
| Brand mark | Existing raster/vector asset | Keep the current mark and accessible brand link. |
| Header and navigation | Semantic HTML and CSS | Preserve dismissible mobile navigation and direct reader action. |
| Hero typography and actions | Semantic HTML and CSS | Match selected hierarchy; black CTA; white outline in Dark mode. |
| Hero atmosphere | Existing `home-ambient.jpg` raster | Use only in the homepage hero, with restrained opacity. |
| Reader product media | Authentic captured raster assets | Capture Light, Sepia, and Dark from the existing reader without code changes. |
| Theme selector | Semantic buttons and Svelte state | Expose pressed state, keyboard focus, persistence, and Automatic system behavior. |
| Paper transition | CSS layout and section geometry | Broad section boundary, not a decorative illustration. |
| Practice sequence | Semantic ordered content | Use rules and numbering rather than cards. |
| Reading coverage | Existing data and semantic links | Prefer compact useful indexes; preserve filters and empty states. |
| Motion | CSS transform and opacity | Purposeful, short, and reduced-motion safe. |

## Non-Literal Translation

The generated concept is a north star, not a raster specification. Core copy, navigation, buttons, controls, and reader data remain semantic and accessible. The reader screenshot is authentic product media rather than a reconstructed UI. The exact generated Hebrew text, generated icon details, and image imperfections are not copied.
